# Maclawrence / Maciboi Portfolio

A lightweight, dark, cinematic personal website made for GitHub Pages.

## Upload to GitHub
Put these directly in the ROOT of your repository:
- index.html
- style.css
- script.js
- assets/

No Node.js, npm, React or build step is required.

## Photo practice feature
There are four local photo selectors:
- Profile
- Southgold / School
- Favourite Food
- Football

Choose a picture and it appears immediately. The browser remembers the selected picture using localStorage. The image is NOT uploaded to a server.

For a permanent photo that everyone sees on GitHub Pages, place the image in `assets/` and reference it from `index.html`.

## Important
The Southgold, food and football cards start as clean placeholders so you can add your own photos rather than using fake images of your school or food.
